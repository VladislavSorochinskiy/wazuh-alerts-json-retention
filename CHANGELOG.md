# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-08-17

### Added

- Safe cleanup of rotated Wazuh alert `.gz` and `.sum` files.
- Configurable retention period with a default of seven days.
- Explicit dry-run and delete modes.
- Hardened systemd oneshot service and persistent daily timer.
- Non-blocking lock against concurrent execution.
- Installer, uninstaller, functional tests, ShellCheck, and GitHub Actions CI.
- English and Russian documentation.
- Contribution guidance, security policy, editor configuration, and repository automation.
